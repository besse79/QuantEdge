# QuantEdge

Application quantitative de recherche et de simulation de portefeuille, indépendante de Weinstein'S et BuffettValue.

**Statut :** amorçage V1, aucune stratégie validée et aucun ordre actif.

Stratégies envisagées : momentum transversal, trend following et gestion du risque. Les facteurs qualité seront introduits uniquement lorsque les données fondamentales historiques seront fiables.

Voir [architecture V1](docs/ARCHITECTURE.md).

Capital PAPER cible : 500 EUR. Données gratuites uniquement. Aucun trading réel.
